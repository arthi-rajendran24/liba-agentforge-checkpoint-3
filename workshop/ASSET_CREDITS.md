# Workshop visual credits

The command core, kitchen-team analogy and evidence-review illustrations were generated with the image generation tool for this AgentForge workshop kit. They are original conceptual illustrations, not photographs of LIBA or the actual team. The main deck uses each once. The diagrams are editable native slide shapes and connectors.

`monsoon-case.png` is the fictional Project Monsoon teaching slide, supplied for the live Gemini image-extraction exercise. It contains assumptions, not commercial market data.

The interface was inspired by https://github.com/arthi-rajendran24/vibe-jarvis . Framework and proposal sources are listed in the PowerPoint speaker notes and main facilitator guide.
