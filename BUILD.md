# Build contract

The project grows cumulatively:

1. Checkpoint 1 owns deterministic business facts and offline tests.
2. Checkpoint 2 adds an adapter, shared service and local interface without replacing the student's tool.
3. Checkpoint 3 adds reviewed multimodal evidence, approved memory and an optional Telegram channel that reuse the shared service.

Business calculations belong only in `src/agentforge/tools.py`. Credentials never belong in source, tests, chat, screenshots or commits.
